## 📌 About
This repository documents my structured practice through LeetCode's **SQL 50** study plan — a curated set of problems covering everything a Data Analyst needs: joins, aggregations, window functions, subqueries, and string manipulation.

Each solution is written, tested, and explained in my own words — because in interviews, it's not enough to *have* the answer, you need to *explain* it.

🎯 **Goal:** Land an off-campus Data Analyst role (target: 12–15 LPA) by demonstrating real, hands-on SQL proficiency.
